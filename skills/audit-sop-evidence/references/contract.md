# Review boundaries

Audit world structure first. With a directory or ZIP, also compare budgets, service projections, exact SOP text and checksum inventory. Literal credential and reviewer-name scans identify markers, not an exhaustive privacy review.

Use only observable grading kinds: accepted action, rejected action, final state, action order, action absence and qualifying evidence used. Each criterion needs a real target and SOP clause. Required failures override the percentage threshold.

Resolve citations against actual clause text or canonical record bodies. Require exact, case-sensitive substrings. Report unsupported or missing evidence instead of guessing.

The wrapper requires the intact repository or an installed Python package. Read `docs/rubric-contract.md` at the complete plugin root for field-level details.
